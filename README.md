# Good Pharm – Manual QA Testing Project

## Overview

Manual QA project evaluating the functionality, usability, responsiveness, and reliability of the Good Pharm website.

## Testing Scope

- 71 manual test cases
- Smoke & Sanity Testing
- Functional Testing
- UI & Responsive Testing
- Positive & Negative Testing
- Boundary Value Testing
- Hebrew RTL Validation
- Defect Reporting & Retesting

## Test Results

- 53 Passed
- 12 Failed
- 4 Not Testable
- 2 N/A
- 74.6% Pass Rate

## Deliverables

- Software Test Report (STR)
- Detailed test cases and execution results
- Jira defect documentation
- QA metrics and recommendations
- Release readiness assessment
